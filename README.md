# nura-basic-terminal

<p align="center">
  <img src="screenshots/firefox-nuraos.png" width="540" alt="Firefox on the NuraOS site, running fullscreen via `app` — the status bar shows the SMS and missed-call indicators next to the signal strength">
</p>

Make a postmarketOS phone usable **without a GUI** — and give it one when
you want it (`app firefox`, above). If your phone runs a bare
VT console (fbcon) — as a hotspot, a server, a mini-terminal — the hardware
buttons do nothing, the console font is unreadably small, there's no way
to see battery or signal without logging in, and no way to scroll back
through what you typed.

This repo fixes all of that:

| Piece | Folder | What it does |
|---|---|---|
| `phone-screen-toggle` | [`buttons/`](buttons/) | Power button turns the screen off and back on; double click toggles the onscreen keyboard — without logging out |
| `phone-font` | [`buttons/`](buttons/) | Volume up/down steps the console font through 16 → 48 px |
| `phone-statusbar` | [`statusbar/`](statusbar/) | A status bar painted over the top of the framebuffer: cellular tech + signal (left), battery + clock (right) — and the same line inside graphical sessions (`--text` mode feeds sway's bar) |
| `phone-gestures` | [`gestures/`](gestures/) | Touchscreen gestures on the console: drag = scroll through tmux scrollback, double tap = TAB (inside the tmux session only) |
| `phone-brightness` | [`brightness/`](brightness/) | Backlight follows the ambient light sensor: dim in the dark, bright in the sun |
| `phone-ir` | [`ir/`](ir/) | Send IR commands with the phone's IR LED: NEC / Samsung / Sony / RC5 / raw timings, or named codes from a config file |
| `sms-send` / `call` | [`telephony/`](telephony/) | Send an SMS, and dial / answer / hang up calls, from the command line |
| `sms-handler` | [`telephony/`](telephony/) | Runs a command for every received SMS — forward it, upload it, archive it — configured in `/etc/phone-sms-handler.conf`; the modem inbox doubles as the retry queue |
| `call-watcher` | [`telephony/`](telephony/) | Rings on incoming calls, lights the screen, shows RING/CALL in the status bar; volume-up answers, volume-down silences the ringer |
| `notify-led` | [`notify/`](notify/) | The notification LED: fast blink while a call rings, steady while active, slow blink for a missed call, double blink for an unread SMS, steady while charging (`notify-clear` dismisses) |
| `ter-148n.psf.gz` | [`fonts/`](fonts/) | A 24×48 console font (3× pixel-scaled Terminus), regenerated by `scale-psf.py` |
| `phone-buttons.toml` | [`buttons/`](buttons/) | hkdm hotkey config binding the buttons to the scripts |
| `app` | [`graphical/`](graphical/) | Run any Wayland app fullscreen: a sway kiosk at 3× scale with the `wvkbd` on-screen keyboard (power double-click toggles it, vol-up + power screenshots to `~/Pictures`), the status bar kept on top |

Each folder's README documents how its piece works, what its installer
does, and what to customize for your device.

Tested on a Xiaomi Mi A2 Lite (*daisy*, msm8953) running postmarketOS v26.06,
1080×2280 screen. Everything is plain shell + Python against sysfs and
`/dev/fb0`, so it should port easily to other devices — see
**Customizing** below.

## Requirements

- postmarketOS (or any Linux with an fbcon VT console and systemd)
- `hkdm` — hotkey daemon (`apk add hkdm`)
- `terminus-fonts` — provides `ter-116n`…`ter-132n` (`/usr/share/consolefonts`)
- `python3` — for the status bar and the gesture daemon
- `tmux` — provides the console scrollback the gestures drive
  (`apk add tmux`)
- for `phone-ir`: a C compiler and the kernel UAPI headers
  (`apk add build-base linux-headers`) — `irsend` is built on the device
- for the telephony tools: `modemmanager` (running), `polkit`, and
  `pulseaudio` + `pulseaudio-utils` (`paplay` for the ring tone) — on
  postmarketOS these are all in the base install
- optional: `buffyboard` (onscreen keyboard; see
  [`buffyboard/`](buffyboard/) if your kernel breaks its console
  resizing) and `ttyescape` (hold vol-down + tap power 3× to switch to
  another VT)
- for `app`: `sway`, `wvkbd`, `seatd` (provides `seatd-launch`) and `grim`
  — `install-graphical.sh` runs `apk add` for all of them

## Install

Copy this directory to the phone (e.g. `scp -r . phone:/tmp/basic-terminal`),
then on the phone as a sudoer:

```sh
doas sh /tmp/basic-terminal/install.sh            # everything
```

Or install one piece at a time — each installer is self-contained and
its behavior is documented in the component's README:

| Installer | Installs |
|---|---|
| `install-buttons.sh` | fonts, power/volume button handling, hkdm bindings, boot font |
| `install-statusbar.sh` | framebuffer status bar + unit |
| `install-gestures.sh` | touchscreen gestures, tmux-wrapped tty1 |
| `install-brightness.sh` | adaptive backlight + unit |
| `install-ir.sh` | IR blaster (compiles `irsend`) |
| `install-telephony.sh` | calls, SMS, ringer, call-watcher, sms-handler |
| `install-notify.sh` | notification LED + unit |
| `install-graphical.sh` | `app` sway kiosk (apk-adds its dependencies) |

All the installers source `backup-helper.sh`. When one overwrites a file
**that actually changed**, the old version is copied, timestamped, into
`<device home>/backup`, so a bad deploy can be rolled back by hand.
Reinstalling an identical file backs up nothing, and only the 2 newest
copies of each file are kept. Tune with `BACKUP_KEEP=` (how many to keep)
and `BACKUP_DIR=` (where).

## Customizing

All the device-specific bits are constants at the top of the scripts, and
the runtime tunables live in `/etc` config files (each with a commented
template in the repo, installed only when none exists) — the component
READMEs list them per piece.

Nothing names the device user: the installers and the graphical scripts
resolve the user at run time as the owner of the single home under
`/home` — by uid, so any username works. The one exception is
`phone-gestures`' `UID` constant (uid 10000, the postmarketOS default).
