# nura-basic-terminal

Make a postmarketOS phone usable **without a GUI**. If your phone runs a bare
VT console (fbcon) — as a hotspot, a server, a mini-terminal — the hardware
buttons do nothing, the console font is unreadably small, and there's no way
to see battery or signal without logging in.

This repo fixes all three:

| Piece | What it does |
|---|---|
| `phone-screen-toggle` | Power button turns the screen (and onscreen keyboard) off and back on, without logging out |
| `phone-font` | Volume up/down steps the console font through 16 → 48 px |
| `phone-statusbar` | A status bar painted over the top of the framebuffer: cellular tech + signal (left), battery (right) |
| `ter-148n.psf.gz` | A 24×48 console font (3× pixel-scaled Terminus), regenerated by `scale-psf.py` |
| `phone-buttons.toml` | hkdm hotkey config binding the buttons to the scripts |

Tested on a Xiaomi Mi A2 Lite (*daisy*, msm8953) running postmarketOS v25.06,
1080×2280 screen. Everything is plain shell + Python against sysfs and
`/dev/fb0`, so it should port easily to other devices — see
**Customizing** below.

## Requirements

- postmarketOS (or any Linux with an fbcon VT console and systemd)
- `hkdm` — hotkey daemon (`apk add hkdm`)
- `terminus-fonts` — provides `ter-116n`…`ter-132n` (`/usr/share/consolefonts`)
- `python3` — for the status bar
- optional: `buffyboard` (onscreen keyboard — its visibility follows the
  backlight, so the power toggle hides/shows it for free) and `ttyescape`
  (hold vol-down + tap power 3× to switch to another VT)

## Install

Copy this directory to the phone (e.g. `scp -r . phone:/tmp/phone-buttons`),
then on the phone as a sudoer:

```sh
doas sh /tmp/phone-buttons/install.sh          # buttons + fonts
doas sh /tmp/phone-buttons/install-statusbar.sh  # status bar
```

What the installers do:

- `install.sh` — installs the font + `phone-screen-toggle` + `phone-font`,
  drops `phone-buttons.toml` into `/etc/hkdm/config.d/`, sets the boot font
  via `FONT=` in `/etc/vconsole.conf` (and `/etc/conf.d/ttyescape.conf` so
  the escape VT matches), restarts hkdm.
- `install-statusbar.sh` — installs `phone-statusbar` + its systemd unit
  (enabled at boot), the `/etc/profile.d` `clear` shim, and pads `/etc/issue`
  with two blank lines so the login prompt starts below the bar.

## How it works

**Power button** (`phone-screen-toggle`): off = backlight 0 + `setterm
--blank force` (the logged-in session on tty1 is untouched); on = `setterm
--blank poke` + restore the saved brightness, then a `SIGUSR1` nudge so
the status bar repaints immediately. buffyboard draws only while
the screen is lit, so the keyboard hides/shows along with it. The
`ttyescape` combo (vol-down held + power taps) is preserved: the script
bails out if `/tmp/ttyescape.tmp` exists, and `phone-font down` ignores
volume presses within 2 s of a power press.

**Font ladder** (`phone-font`): steps between the stock Terminus sizes
(16/20/24/28/32 px) plus a generated 48 px one; the current step lives in
`/run/phone-buttons/font-index` (volatile — resets to the biggest after a
reboot, which is usually what you want on a phone).

**Big font** (`scale-psf.py`): Terminus tops out at 32 px, so
`ter-148n.psf.gz` is ter-116n scaled 3× to 24×48. Regenerate with
`python3 scale-psf.py /usr/share/consolefonts/ter-116n.psf.gz ter-148n.psf.gz 3`.
Gotchas handled: PSF1 unicode tables are little-endian u16 with 0xFFFF
terminators / 0xFFFE sequence separators and contain UTF-16 surrogate
pairs; PSF2 wants UTF-8 values with 0xFF/0xFE markers.

**Status bar** (`phone-statusbar`): a Python daemon that paints only the
top 96 px band of `/dev/fb0` — the notch zone, useless for text anyway —
every 10 s, and immediately when the screen turns on: `phone-screen-toggle`
sends it `SIGUSR1`, which interrupts its sleep. While the screen is dark
the daemon sleeps in 30 s chunks (a backlight read as a safety net), so it
costs essentially nothing between repaints. The terminal below is never
redrawn; text that scrolls under the bar is healed by the next repaint.
The bar is a **fixed** height with its own fixed 24×48 font, so it never
moves when you change the console font. Values (battery from
`/sys/class/power_supply/*/capacity|status`, cellular from `mmcli -m any`)
are fetched only once per repaint.

## Customizing

All the device-specific paths are constants at the top of the scripts:

- `phone-screen-toggle`: `BL=` (backlight sysfs dir)
- `phone-statusbar`: `FB`, `SYSFB`, `BACKLIGHT`, `BATTERY`, `BAR_FONT`,
  `BAR_H` (px), `EDGE_MARGIN`, `TEXT_MARGIN`, and the `TECH_LABEL` map for
  access-technology names
- Colors are RGB tuples near the top of `phone-statusbar`

**Framebuffer gotcha:** read `stride` from
`/sys/class/graphics/fb0/stride` and trust it over `width * 4` — this
device reports 1080×2280 @ 32bpp but a stride of **4352**, not 4320
(32-byte row padding). If your bar comes out diagonal or smeared, this is
why. The pixel format assumed is BGRx little-endian, which matches the
common `FB_VISUAL_TRUECOLOR` + 32bpp case.

If your device has no notch, shrink `BAR_H` to `2 × font_height` of
whatever the smallest console font you use is, so the bar never eats more
than two terminal rows.

## Files

- `install.sh`, `install-statusbar.sh` — root installers (run from
  `/tmp/phone-buttons` on the device)
- `phone-buttons.toml` — hkdm bindings
- `phone-screen-toggle`, `phone-font` — shell scripts (installed to
  `/usr/local/bin/`)
- `phone-statusbar` — Python daemon; `phone-statusbar.service` — its unit
- `phone-statusbar-profile.sh` — `clear` shim installed to
  `/etc/profile.d/`, keeps the prompt below the bar
- `scale-psf.py` — PSF1 → PSF2 integer font scaler
- `ter-116n.psf.gz` — pristine source font (copy of stock Terminus);
  `ter-148n.psf.gz` — the generated 24×48 result
